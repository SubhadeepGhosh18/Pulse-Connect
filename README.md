# ⚡ PulseConnect

> **Connecting the right talent to genuine projects with zero friction.**

PulseConnect is a modern freelancing and talent matching platform designed to solve two major challenges: freelancers finding genuine, high-value work, and clients securing verified talent with the exact required skill set.

---

### ✨ Key Features

- **Smart Discovery Marketplace:** Filter and search verified listings by category, tech stack, and budget.
- **Dual-Role Workflows:** Tailored user experience for **Clients** (post projects & evaluate proposals) and **Freelancers** (browse & pitch).
- **Streamlined Bidding:** Fast, structured proposal creation and real-time review.
- **Modern UI:** Obsidian glassmorphic interface inspired by Linear and Vercel design systems.

---

### 🛠️ Tech Stack

- **Framework:** Next.js (App Router), React, TypeScript
- **Styling:** Tailwind CSS
- **Database & ORM:** PostgreSQL / Prisma ORM
- **Authentication:** JWT / Role-based access control
